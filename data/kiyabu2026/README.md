# Data extracted from Kiyabu, Shkatulov, Ahmed, Greene, Huinink & Siegel (2026)

"Materials for thermochemical energy storage and conversion: attributes for low-temperature applications",
Materials Horizons 13, 2087-2126. DOI 10.1039/d5mh01794g. Open access, CC BY-NC 4.0.

Values are copied verbatim from the published tables (page numbers are journal pages):

| File | Paper table | Page |

| table4_class_overview.csv | Table 4 - overview of low-temperature TCES material classes | 2097 |
| table5_salts.csv | Table 5 - crystal-level properties of salts (12 mbar hydration / 20 mbar dehydration; data from Donkers et al. 2017) | 2100 |
